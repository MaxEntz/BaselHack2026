# Sésame logo

![Sésame](sesame-wordmark.png)

**Wordmark:** "Sésame" in a high-contrast serif, ink `#1A2321`, with a terracotta sesame seed (`#CA6C4E`) as the accent on the `é`, on `#FAF8F4`, close to the palette below.

| File | Use |
| --- | --- |
| `sesame-wordmark.png` | Source wordmark, 760 × 317, on its `#FAF8F4` background. |
| `sesame-wordmark-transparent.png` | Same, trimmed, transparent background (the background color turned to alpha); used in the merchant chat header (`code/web/public/wordmark.png`). |
| `sesame-seed.svg` | The orange seed alone, traced from the wordmark (fill `#CA6C4E`, highlight `#EBD0C4`): the app icon. The web app's `favicon.svg`. |
| `sesame-icon-32.png` / `sesame-icon-512.png` | The seed rendered from `sesame-seed.svg`, transparent background. The 32 px one is the web app's PNG favicon. |
| `sesame-icon-180.png` | The seed on a rounded `#FAF8F4` tile (iOS fills transparency with black): the web app's Apple touch icon. |

## Earlier mark: Counterpart

Drawn when the product was called "Merchant Agents". No Sésame glyph replaces it yet, so it stays available as a vector icon.

**Counterpart:** two complementary pieces meet across an open, stepped channel: a merchant and an agent connecting through a shared interface. Rounded outer corners soften the precise fit. The mark uses two hand-written paths and stays legible at 16 px.

Accent: terracotta **`#D96545`**. Dark monochrome: **`#182321`**. Light monochrome: **`#FAF8F4`**. Each SVG uses at most two colors; all backgrounds are transparent.

| File | Use |
| --- | --- |
| `mark.svg` | Primary color glyph, on light or dark backgrounds; minimum 16 px. |
| `mark-mono-dark.svg` | Dark glyph on a light background; single-color printing. |
| `mark-mono-light.svg` | Light glyph on a dark background. |
| `lockup.svg` | Superseded by the Sésame wordmark: it still spells "Merchant Agents". Kept for the record. |
| `favicon.svg` / `favicon-32.png` | Browser icon: scalable SVG and transparent 32 × 32 PNG fallback. |

See [the final preview](preview.png) and [the four-concept comparison](concepts/contact-sheet.png). `concepts/renders/` contains every concept at 16, 32 and 128 px on both backgrounds; `previews/` contains final color and monochrome proofs. All SVG viewBoxes are square.

Visual review and limited web comparison are documented in [concepts/README.md](concepts/README.md). No reverse-image search or trademark clearance was performed.
